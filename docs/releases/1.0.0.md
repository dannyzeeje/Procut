## Color, audio, and a touch-first editor

- **Color workspace.** Grade shots in reorderable clip layers, with independent red, green, and blue gamma and gain, wheels, curves, and before-and-after comparison. Convert Sony S-Log3 with S-Gamut3.Cine or S-Gamut3, and Panasonic V-Log with V-Gamut, to the Rec.709 working space.
- **LUT library.** Import a .cube file once and reuse it across projects. Different LUTs with the same filename can coexist.
- **Audio workspace.** Mix tracks with gain, stereo balance, mute, and solo. Monitor the stereo master, edit clip volume keyframes and fades, and apply low-pass and high-pass filters. Mark a timeline range to apply low-pass to the mix for that span.
- **Touch controls.** Speed, color, and audio use wider adjustment controls with exact value entry. The Edit and Audio workspaces remember separate timeline zoom levels.
- **Timeline fixes.** Multi-selection exposes batch actions, with Split and Merge available for compatible selections. Reverse and Optical Flow use separate progress labels, and Android media processing uses PCM internally for these generated clips.

The APK targets ARM64 Android devices running Android 8.0 or later. Device checks for multi-selection, Reverse, Optical Flow, and the new workspaces are pending.
